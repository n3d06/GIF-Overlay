GIF Overlay GitHub

Pin GIFs and images on top of your screen.

A tiny, free Windows app. Borderless, translucent and resizable — about 300 KB.

Download for Windows

Windows 10 / 11 · MIT licensed

What it does

  • Keeps an image above every other window.
  • Transparent GIFs and PNGs blend in; fade the whole window from 10% to 100%.
  • Drag the corner to scale, or an edge to stretch one side.
  • Open as many images as you like, each in its own window.
  • GIF, PNG, JPG, BMP, TIFF and WebP.
  • A small history dashboard remembers what you opened.

The exe isn’t code-signed yet, so Windows SmartScreen may show a warning. The source is public and each release is built by GitHub Actions.
